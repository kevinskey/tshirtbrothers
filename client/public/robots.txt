# T-Shirt Brothers — robots.txt
#
# Policy: welcome crawlers that can SEND US CUSTOMERS (traditional
# search indexes and the retrieval crawlers behind AI answer engines).
# Keep customer/account surfaces and the admin app out of all indexes.
# Model-TRAINING-only crawlers are listed separately at the bottom so
# the decision for each is explicit rather than inherited from "*".
#
# The distinction matters and is easy to get wrong, because several
# vendors run two or three differently-named bots:
#
#   OpenAI    OAI-SearchBot  -> indexes for ChatGPT search results (ALLOW)
#             ChatGPT-User   -> live fetch when a user's prompt needs
#                               the page right now (ALLOW)
#             GPTBot         -> training corpus collection (see below)
#   Google    Googlebot      -> web search + AI Overviews (ALLOW)
#             Google-Extended-> Gemini training/grounding (see below)
#   Anthropic ClaudeBot      -> training (see below)
#             Claude-User / Claude-SearchBot -> user-driven fetch and
#                               search indexing (ALLOW)
#   Perplexity PerplexityBot -> search index (ALLOW)
#             Perplexity-User-> live user-driven fetch (ALLOW)
#   Microsoft bingbot        -> Bing + Copilot grounding (ALLOW)
#
# Blocking GPTBot does NOT remove us from ChatGPT's search results —
# that is OAI-SearchBot's job. Likewise blocking Google-Extended does
# not affect Google Search or AI Overviews ranking.

# ---------------------------------------------------------------
# Default: everything else
# ---------------------------------------------------------------
# NOTE ON ORDERING: every Disallow is listed BEFORE the closing
# "Allow: /" in each group. Google and Bing resolve conflicts by
# longest-match so order is irrelevant to them, but simpler parsers go
# first-match-wins — with "Allow: /" at the top of the group they
# treated every path as crawlable and silently ignored every Disallow
# below it. Keep "Allow: /" last when editing these groups.
User-agent: *

Disallow: /auth
Disallow: /api/
